# Google Play listing: German (de-DE)

- **App name:** KairoMSX

## Short description

Spielen Sie Ihre MSX-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit KairoMSX spielen Sie Ihre eigenen MSX-Spiele auf Android. Fügen Sie Ihre Modul-, Disketten- oder Kassettenabbilder hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer MSX-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele sind nicht enthalten. Die meisten Modulspiele laufen mit dem enthaltenen C-BIOS; Disketten-, Kassetten- und turbo-R-Spiele brauchen ein BIOS von Ihrem eigenen Gerät.

Sie können dieselbe App auch kostenlos über die GitHub Releases von KairoMSX herunterladen. Die Version bei Google Play hat dieselben Funktionen.

KairoMSX ist ein unabhängiges Projekt auf Basis von openMSX und C-BIOS.
