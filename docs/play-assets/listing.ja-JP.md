# Google Play listing: Japanese (ja-JP)

- **App name:** KairoMSX

## Short description

Android で、お手持ちの MSX ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

KairoMSX は、お手持ちの MSX ゲームを Android で遊べるアプリです。カートリッジ、ディスク、テープのイメージを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（MSX キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームは含まれていません。ほとんどのカートリッジゲームは同梱の C-BIOS で動作します。ディスク、テープ、turbo R のゲームには、お手持ちの実機の BIOS が必要です。

同じアプリを KairoMSX の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

KairoMSX は、openMSX と C-BIOS を使った独立したプロジェクトです。
