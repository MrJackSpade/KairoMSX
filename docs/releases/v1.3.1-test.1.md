# v1.3.1-test.1

The first test build of KairoMSX, for MSX games. It is not published to Google Play.

- Runs MSX, MSX2, MSX2+ and turbo R cartridges, disks and tapes. Cartridge games start on C-BIOS, which comes with the app.
- Disks that start from MSX-DOS2 boot it on the turbo R, with MSX-DOS2's files imported from your own copies.
- Machine settings for the machine and its memory.
- A game library with catalog titles, descriptions and artwork, from a folder of your games; archives are read in place.
- Controller, touch and on-screen keyboard controls, with researched defaults and a button mapping for every game.
- Save states, and per-game settings that override the all-games ones.

Games are not supplied. Disk, tape and turbo R games need the BIOS of a real MSX from your own machine (Panasonic FS-A1WSX, FS-A1GT or Philips NMS 8250); import it in **Menu › Machine**. Both APK variants have the same features.
