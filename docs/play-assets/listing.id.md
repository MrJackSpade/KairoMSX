# Google Play listing: Indonesian (id)

- **App name:** KairoMSX

## Short description

Mainkan game MSX Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

KairoMSX memungkinkan Anda memainkan game MSX milik Anda sendiri di Android. Tambahkan image cartridge, disk, atau kaset Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard MSX. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game tidak disertakan. Sebagian besar game cartridge berjalan dengan C-BIOS bawaan; game disk, kaset, dan turbo R memerlukan BIOS dari mesin Anda sendiri.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases KairoMSX. Versi Google Play memiliki fitur yang sama.

KairoMSX adalah proyek independen yang menggunakan openMSX dan C-BIOS.
