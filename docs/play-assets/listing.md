## Short description

Play your MSX games on Android with touch controls or a gamepad.

## Full description

KairoMSX lets you play your own MSX games on Android. Add your cartridge, disk or tape images, pick a game from the library, and play with a gamepad or on-screen controls, including an MSX keyboard. On a two-screen handheld, the game and controls can use separate displays.

Games aren't included. Most cartridge games run with the included C-BIOS; disk, tape and turbo R games need a BIOS from your own machine.

You can also download the same app free from KairoMSX GitHub Releases. The Play version has the same features.

KairoMSX is an independent project using openMSX and C-BIOS.
